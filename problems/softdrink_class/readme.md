# Softdrink Class

Write a Python class to keep track of softdrinks for our side business selling drinks to students between classes.  It should be called `Softdrink`. It should keep information about the drink name (can only be Mt. Dew, Dr. Pepper, or Diet Pepsi), the size in ounces (an int, can only be 12, 16, 20, or 32), and the cost (a float, cannot be negative). It should have a `__str__` method that is of the form "20 ounce Dr. Pepper - $1.99" (but obviously uses the values of the instance).

The class should raise `TypeErrors` and `ValueErrors` when it encounters an incorrect type or value. Examine the test cases to see what values should be passed to the constructor.
